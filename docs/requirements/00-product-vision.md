# 产品定位与价值主张

> 这是 Lumen AI Platform 的"电梯演讲"——30 秒讲清楚是什么、为什么、卖给谁。
> 适合:销售/售前/客户/新员工快速了解。

---

## 1. 一句话定位

**Lumen AI Platform 是企业级 AI Agent 平台,让企业 1 周内就能搭出自己的"AI 员工"——能聊天、能查知识、能画图、能做视频、能跑工作流,还能嵌入到客户网站/桌面端。**

对标 Coze / Dify / 钉钉智能伙伴,但**完全自托管、数据不出本地、支持私有模型**。

---

## 2. 解决什么问题

企业用大模型有三个痛点:

| 痛点 | 描述 | Lumen 解法 |
|------|------|-----------|
| **数据出不去** | 客户对话要发给 OpenAI,合规不让 | Ollama 本地模型 + 私有化部署 |
| **业务接不上** | ChatGPT 是空壳,不能查我公司的产品手册 | 知识库 RAG(上传 PDF → 自动向量化) |
| **流程跑不通** | AI 只能"聊天",真实的"查订单 → 发邮件 → 通知"流程跑不了 | 可视化工作流(22 节点,DAG 编排) |

更进一步,企业还有:

- **"我想让 AI 替我画公众号文章"** → 公众号助手(M32)
- **"我想让 AI 帮我看销售数据"** → 智能问数 Text2SQL(M33)
- **"我想把 AI 嵌到我公司网站"** → Widget 一行代码嵌入
- **"我想让 AI 在我电脑本地跑(财务数据敏感)"** → Electron 桌面端

## 3. 核心能力(4 大支柱 + 1 横切)

### 支柱 1:知识库 RAG
- 上传 PDF/Word/Excel/Markdown → Docling 解析 → 切块 → Embedding → FAISS + Elasticsearch
- 混合检索:向量相似度 + 关键词 BM25 + Rerank 精排
- Per-KB Embedding 模型(每个 KB 可选不同的 embedding)

### 支柱 2:AI Agent + 多 Agent 团队
- 单 Agent:系统提示词 + 模型 + 工具 + 记忆策略 + 知识库
- 多 Agent:LangGraph `StateGraph` 编排,manager → workers 路由
- 5 轮 tool loop 工具调用,工具包括 KB 检索 / HTTP / Code / 工作流 / MCP tool

### 支柱 3:可视化工作流
- React Flow 画布拖拽,22 节点
- 节点类型:LLM / Code / HTTP / Tool / Knowledge Retrieval / Template Transform / Parameter Extractor / Question Classifier / Variable Assigner / Variable Aggregator / 条件分支 / 并行 / 输入 / 输出
- 错误处理 / 重试 / 超时 共享基础设施

### 支柱 4:专业内容工厂(媒体流水线)
- 文字 → 图片生成(OpenAI/Stability/Ollama)
- 文字 → TTS 语音(Edge TTS/Piper/OpenAI)
- 文字 → SRT 字幕(中英混合)
- 图片 + 文字 → 视频合成(ffmpeg 拼装)
- 全部可触发、可调度、可作工作流节点

### 横切:多渠道交付
- Web 后台(Next.js 15)
- 桌面端(Electron 33,Windows/macOS/Linux)
- 第三方网站嵌入(`<lumen-chat>` Lit Web Component,一行 `<script>`)
- 微信生态(公众号助手)

## 4. 目标客户

### 核心买家
- **中型企业(100~2000 人)** 的 IT 部门 / AI 应用团队 / 数字化转型办公室
- **行业**:金融 / 法律 / 制造 / 教育 / 医疗 / 政府 / 零售
- **场景**:智能客服 / 内部知识库 / 销售助理 / 文档自动化 / 数据问答

### 关键决策点
| 维度 | 我们能提供 |
|------|----------|
| **数据安全** | 全私有化部署,数据不出企业内网 |
| **模型灵活** | Ollama 本地 + OpenAI 兼容 + 自定义 provider |
| **业务集成** | MCP 协议、HTTP 节点、工具调用,接得进 ERP/CRM |
| **交付渠道** | Web / 桌面 / Widget,不用每个终端都重做 |
| **可观测** | LLM 调用级日志 + trace,出问题能定位到 prompt |

### 我们不做
- ❌ **不是 C 端产品** —— 不做个人助理、不做 ToC 营销
- ❌ **不是基础大模型厂商** —— 不训练基模,只做应用层
- ❌ **不是 BI 工具** —— 智能问数只回答"查数据"类问题,不做图表编辑

## 7. 我们的承诺

1. **30 分钟启动**:Docker compose + 一键脚本,30 分钟内本地跑起来
2. **1 周交付**:客户拿到平台后 1 周内能搭出第一个 AI 应用
3. **可观测**:每个 LLM 调用都留日志,出问题 5 分钟内能定位
4. **不绑定**:不锁用户到特定 LLM,OpenAI / Ollama / 自定义模型随便切

## 9. 我们和"Coze/Dify"用户的常见问答

> **Q:和 Coze 比,我们强在哪?**
> A:Coze 是字节系的 SaaS,数据在云端,且没有桌面端、没有客户 CRM、没有 RAG 评测、没有公众号。Lumen 是私有化 + 多渠道 + 业务功能更全。

> **Q:和 Dify 比呢?**
> A:Dify 主要是 Web 工作流。Lumen 多出 Electron 桌面端、Widget 嵌入、公众号助手、智能问数、视频合成、股票素材库、CRM。

> **Q:谁在用?**
> A:已在金融 / 教育 / 制造行业落地。客户在内部跑 3~6 个月后,通常会再增购 1~2 个租户。

> **Q:能否接入我的 ERP?**
> A:可以。通过 MCP 协议 / HTTP 节点 / Tool 工具,工作流可以直接调用 ERP 接口。Lumen 还支持自定义 provider / 节点。
